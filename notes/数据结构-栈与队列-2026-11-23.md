## 一、知识点大纲

### 1. 总体定位
- 栈和队列都是**操作受限的线性表**（老师强调：考试重点）

### 2. 栈（Stack）
- 特性：后进先出（LIFO），只允许在一端插入和删除
  - 操作端叫栈顶（top），另一端叫栈底
- 基本操作：push 入栈、pop 出栈、peek/gettop 取栈顶元素（不删除）
- 实现方式
  - 顺序栈：数组实现，需判满 `top == maxsize - 1`（⚠️ 待确认：原文"好像是这样"，判满条件与 top 初值的约定有关）
  - 链栈：链表实现，采用头插法，一般不会满
- 应用：函数调用栈、括号匹配、表达式求值（中缀转后缀用栈）、递归、浏览器后退（⚠️ 待确认：原文标注"？？"）
- 出栈序列计数：n 个元素进栈，出栈序列种数 = 卡特兰数 `C(2n,n)/(n+1)`，n=3 时为 5 种

### 3. 队列（Queue）
- 特性：先进先出（FIFO），队尾（rear）插入、队头（front）删除
- 顺序队列与假溢出
  - 假溢出：rear 已到数组末尾，但数组前部仍有空位（原文重点标注"！！"）
  - 解决：循环队列，下标取模回绕 `rear = (rear + 1) % maxsize`
- 循环队列的判空 / 判满
  - 判空：`front == rear`
  - 判满方案一：牺牲一个存储单元，`(rear + 1) % maxsize == front`
  - 判满方案二：增设 size 计数器
- 链队列：带头结点的链表，front 指向头结点，rear 指向尾结点

### 4. 双端队列（Deque）
- 两端都可插入和删除
- 变体：输入受限的双端队列、输出受限的双端队列（⚠️ 待确认：原文"没太懂，回头问"）

## 五、自测题

1. 给定入栈顺序，如何判断某个出栈序列是否合法？
   <details><summary>参考答案</summary>用一个栈模拟入栈/出栈过程：按入栈顺序依次压栈，每当栈顶等于期望的下一个出栈元素就弹出；若最终无法匹配完整个出栈序列，则该序列非法。</details>

2. 循环队列为什么常采用"牺牲一个存储单元"的方法判满？
   <details><summary>参考答案</summary>若不牺牲单元，队满与队空都表现为 front == rear，无法区分；牺牲一个单元后，满的条件变为 (rear+1)%maxsize == front，与判空条件区分开。也可改用 size 计数器判满。</details>

3. 简述"用栈判断回文"的思路（本次作业）。
   <details><summary>参考答案</summary>将字符串前半段依次入栈，再逐个出栈与后半段字符比较（奇数长度跳过中间字符）；全部相等则为回文。利用了栈 LIFO 使前半段逆序的特性。</details>

4. 带头结点的链队列中 front、rear 各指向哪里？
   <details><summary>参考答案</summary>front 指向头结点，rear 指向尾结点；入队在 rear 之后插入并更新 rear，出队删除头结点之后的首元结点。</details>
