# 学习笔记整理（study-notes）

把杂乱的课堂原始笔记整理成一份可直接用于复习的结构化 Markdown 资料，并把记忆卡片登记到 CSV 复习表。

## 流程

1. 确定输入：用户粘贴的笔记文本，或工作区内的笔记文件路径。两者都没有时只问一次要整理的内容。
2. 通读原始笔记，识别科目与主题（如"数据结构—栈与队列"）。原始笔记中语义模糊或疑似笔误处，保留原文并标注 `⚠️ 待确认`，禁止编造原始笔记中不存在的知识点。
3. 按 `assets/template.md` 的结构生成整理稿，要求：
   - 知识点大纲：按逻辑层级重排，最多三级标题；
   - 核心概念表：术语 / 定义 / 例子或备注，覆盖笔记中全部术语；
   - 重点与难点：各不超过 5 条，来自原始笔记强调的内容；
   - 记忆卡片：5–10 组问答，问题具体、答案一句话可背；
   - 自测题：3–5 题，答案放在 `<details>` 折叠块中；
   - 复习计划：按艾宾浩斯间隔给出创建日 +1 / +3 / +7 天三个日期。
4. 保存整理稿到 `<workspace>/notes/<科目>-<主题>-<YYYY-MM-DD>.md`（目录不存在则创建），文件名使用中文即可。
5. 把记忆卡片写成临时 JSON 数组（字段：subject、topic、question、answer），保存到系统临时目录，然后执行登记脚本（必须用此脚本，不要手写 CSV）：

   ```powershell
   python <skill目录>/scripts/add_flashcards.py <cards.json> <workspace>/notes/flashcards.csv
   ```

   脚本会追加卡片并自动计算下次复习日期（创建日 +1 天），首次运行自动建表头。执行成功后删除临时 JSON。
6. 向用户汇报：整理稿与 flashcards.csv 的文件链接、卡片数量、最近一次复习日期。

## 约束

- 输出语言与原始笔记一致（默认中文）。
- 不修改原始笔记文件。
- flashcards.csv 只追加不覆盖，保证多次调用可累积复习库。
